# Interface assets

The app embeds static Plus Jakarta Sans instances at weights 500, 600 and 700. The font is distributed under the SIL Open Font License in `OFL.txt`; source and checked-in file hashes are in `provenance.json`.

`reeb.ico` and `reeb-tray.png` are derived from the project-supplied icon in `assets/brand/`. They are checked in so normal builds do not require image-generation tools.
